# Getting Started with Ask Gordon

This guide will help you get up and running with Gordon, Docker's AI assistant.

## Prerequisites

Before you can use Ask Gordon, ensure you have:

- **Docker Desktop 4.38.0 or later** installed on your system
- An active Docker Desktop installation
- Basic familiarity with Docker concepts

## Installation Steps

1. **Update Docker Desktop**
   - Download the latest version from [Docker's official website](https://www.docker.com/products/docker-desktop/)
   - Ensure you have version 4.38.0 or later

2. **Enable Ask Gordon**
   - Gordon is not enabled by default
   - Open Docker Desktop
   - Navigate to Settings
   - Look for the "Ask Gordon" or AI features section
   - Enable the feature

## First Steps

### Using Gordon in Docker Desktop

1. Open Docker Desktop
2. Look for the "Ask Gordon" view in the interface
3. Click on it to open the AI assistant
4. Start with a simple question like "How can you help me?"

### Using Gordon via CLI

1. Open your terminal
2. Use the command: `docker ai`
3. Follow the prompts to interact with Gordon

## Basic Commands

Here are some example interactions to get you started:

```bash
# Ask Gordon for general help
docker ai "How can you help me with Docker?"

# Get help with a Dockerfile
docker ai "Can you review my Dockerfile for improvements?"

# Troubleshoot container issues
docker ai "My container keeps crashing, can you help?"

# Security analysis
docker ai "Check my image for vulnerabilities"
```

## What to Expect

Gordon can help you with:
- Dockerfile optimization suggestions
- Container troubleshooting steps
- Security vulnerability identification
- Migration to Docker Hardened Images
- General Docker best practices
