## 🤖 What is Ask Gordon?

Gordon, also known as "Ask Gordon," is a personal AI assistant embedded in Docker Desktop and the Docker CLI. It's designed to streamline your workflow and help you make the most of the Docker ecosystem.

### Key Features

Gordon can assist with:
- **Improving Dockerfiles** - Get suggestions for optimization and best practices
- **Running and troubleshooting containers** - Debug issues and get solutions
- **Finding vulnerabilities or configuration issues** - Security and configuration analysis
- **Migrating Dockerfiles to use Docker Hardened Images (DHI)** 

## 🚀 Getting Started

### Prerequisites

- Docker Desktop version **4.38.0 or later**
- Gordon is **not enabled by default** and requires manual activation

### How to Access Gordon

You can access Gordon in two ways:

1. **Docker Desktop GUI**: Use the "Ask Gordon" view in Docker Desktop
2. **Command Line**: Use the `docker ai` CLI command
